# SKKU-Hub 프로토타입 (12조 최종 발표 시연용)

iCampus와 연결되는 Lecture Hub를 노트북 화면 기준으로 만든 웹 프로토타입입니다.
서버 없이 브라우저만으로 동작하며, AI 분석 결과는 **미리 준비한 시연 데이터**를 생성 연출과 함께 보여 줍니다.

## 실행 방법
Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev
```
브라우저에서 http://localhost:5173 을 엽니다.

## 링크로 공유 (GitHub Pages)
`main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 자동으로 빌드해서 배포합니다.
1. 저장소 **Settings → Pages → Source: GitHub Actions** 선택 (처음 한 번)
2. 푸시 후 1~2분 뒤 `https://<GitHub아이디>.github.io/<저장소이름>/` 에서 열림
- 무료 계정은 저장소가 **Public**이어야 Pages를 쓸 수 있습니다.
- 보는 사람마다 진행 상태(할 일, 업로드 파일)는 각자 브라우저에만 저장됩니다.

## 화면 구조
- **과목 화면** (왼쪽에서 과목 선택): 과목 홈 → 할 일 · 개념 · 필기 · 퀴즈 · 자료를 과목 전체 기준으로 모아 봄
- **강의 화면** (과목 홈의 "강의 열기" 또는 왼쪽 강의 목록): 강의 보기 · AI 분석 · 할 일 · 필기 점검 · 퀴즈 · 자료를 그 강의 기준으로 봄
- 과목 화면의 항목을 누르면 근거가 있는 강의·시점으로 바로 이동합니다.

## 기능과 구현 방식

| 기능 | 위치 | 구현 방식 |
|---|---|---|
| iCampus 사이드바 → Lecture Hub 진입 | 첫 화면 | iCampus 모형 화면 |
| 과목·강의 선택, 강의 직접 추가 | 왼쪽 목록 | 실제 구현 |
| 과목 홈 (메뉴 카드 요약 숫자, 강의 목록) | 과목 화면 | 실제 구현 (할 일·필기 점검·퀴즈 상태로 계산) |
| 강의 음성 재생 / 슬라이드 재생 모드 | 강의 보기 | 실제 구현 (TTS로 만든 강의 음성, 영상이 있으면 영상 재생) |
| 스크립트·타임스탬프·슬라이드 동기화 | 강의 보기 | 실제 구현 (클릭 이동, 현재 문장 강조, 자동 스크롤) |
| 전공용어 원문/한글/EN 전환 | 상단 "용어" | 실제 구현 (한글로 바꿀 때 을/를·이/가 같은 조사 자동 보정) |
| 과목 전체 검색 | 상단 검색창 | 실제 구현 (스크립트·슬라이드·개념) |
| 추가 설명·구두 정정·과제·공지·강조 | 강의 화면 > AI 분석 | 예시 결과 + 생성 연출, 근거 위치 이동은 실제 |
| 슬라이드 정정 주석 | 강의 보기 | 분석 후 표시 (원본은 수정하지 않음) |
| 할 일 (자동 추가 → 확인 → 완료) | 과목 화면·강의 화면 > 할 일 | 실제 구현 (브라우저에 저장) |
| 과목 개념 지도 · Concept Chain · 교재 구절 | 과목 화면 > 개념 | 예시 데이터 + 지도 배치·강의 간 이동은 실제 |
| 필기 모아 보기 / 필기 점검 (누락·불일치) | 과목 화면 > 필기 / 강의 화면 > 필기 점검 | 예시 결과 + 생성 연출, 필기 수정 시 "오래됨" 표시 |
| 퀴즈 정답 근거 추적 | 과목 화면·강의 화면 > 퀴즈 | 예시 결과 + 정답 미공개 문항 잠금 |
| 자료 업로드·미리보기·영상 교체 | 자료 | 실제 구현 (브라우저 IndexedDB 저장, 형식·용량 검사) |
| 처리 중·처리 실패 상태 | 운영체제 과목 | 예외 상황 안내 화면 (실패 이유 + 다시 시도) |

## 시연 순서 예시 (약 4분)
시작 전에 오른쪽 위 ⚙ → **시연 데이터 초기화**를 눌러 처음 상태로 만듭니다.

1. **iCampus 대시보드** → **Lecture Hub 열기**
2. **과목 홈 (소프트웨어공학개론)**: 할 일·개념·필기·퀴즈·자료를 과목 단위로 모아 보는 화면 소개. 아직 할 일 카드에는 "AI 분석 후 자동 추가"
3. 강의 목록에서 **Lecture 03 강의 열기** → **강의 보기**
   - 재생: 강의 음성에 맞춰 슬라이드가 넘어가고 현재 문장이 강조됨
   - 스크립트 문장을 눌러 그 시점으로 이동
   - 상단 **용어**를 원문 → **한글** → **EN**으로 바꿔 전공용어 표기 전환
4. **AI 분석** 탭 → **AI 분석 실행**
   - 구두 정정 카드 "XP 반복(iteration) 주기 정정" → 근거 **3:09**로 이동 → 슬라이드 9에 정정 주석 (원본은 그대로)
5. 아래 알림의 **할 일 보기** → HW3·Quiz 3이 "확인 필요"로 추가됨 → HW3 마감일 **이 날짜로 확정**
6. 왼쪽 **Lecture 03** → **필기 점검** 탭 → **필기 점검 실행** → "반복 주기: 2~3개월" 줄이 **불일치**로 표시됨
7. **퀴즈** 탭 → Quiz 3 **Q2 오답** → **강의 근거 추적** → 1순위 교수님 정정 발언(3:09)으로 이동
8. **과목 홈으로** → 카드 숫자가 바뀐 것 확인 (할 일 진행 중, 필기 불일치 2, 퀴즈 오답 2)
9. **개념** → 위쪽 **과목 개념 지도**에서 **점진적 개발** 클릭 → 아래 Concept Chain에서 Lecture 02 → 03 흐름 확인 → 시점 버튼으로 Lecture 02로 이동
10. (선택) 왼쪽 **운영체제** → Lecture 01 **처리 실패** 화면: 실패 이유와 다시 시도 (예외 상황 처리)

## 브랜치 작업 규칙

| 브랜치 | 담당 | 주로 고치는 곳 |
|---|---|---|
| `main` | 공용 (항상 잘 돌아가는 버전) | 직접 커밋하지 않고 Pull Request로만 합침. 합치면 공유 링크 사이트가 자동 갱신됨 |
| `data` | 데이터 담당 | `src/data/`, `public/videos/`, `public/slides/` |
| `ui` | 구현 담당 | `src/components/`, `src/styles.css`, `src/store.jsx` |

두 사람이 고치는 폴더가 겹치지 않아서 충돌이 거의 나지 않습니다. 단, `src/data/index.js`(강의 등록)를 구현 쪽에서 고쳐야 하면 미리 말해 주세요.

### 처음 한 번
```bash
git clone <저장소 주소>
cd <저장소 이름>
npm install
git switch data    # 구현 담당은 git switch ui
```

### 작업할 때마다
```bash
git pull origin main        # 상대가 합친 내용 먼저 받기
npm run dev                 # 화면 확인하면서 작업
git add .
git commit -m "Lecture 03 대본 타임스탬프 수정"
git push
```
그다음 GitHub에서 **Pull Request (`data` → `main`)**를 만들고, 상대가 화면을 확인한 뒤 **Merge**합니다.

- 명령어가 익숙하지 않으면 **GitHub Desktop** 앱으로 같은 작업(브랜치 선택 → Commit → Push → Pull Request)을 버튼으로 할 수 있습니다.
- 영상 파일은 GitHub 제한 때문에 **100 MB 이하**로 줄여서 올려 주세요.

## 폴더 구조
```
src/
  data/          시연 데이터 (데이터 담당이 수정) → DATA_FORMAT.md 참고
  components/    화면 (과목 화면: CourseHome·ConceptTab·CourseNotes 등, 강의 화면: 탭별 파일)
  lib/           날짜 형식, 파일 저장, 과목 홈 요약 계산
  store.jsx      앱 상태 (localStorage 저장), 재생 시각, 강의 이동
  styles.css     디자인
public/audio/    강의 TTS 음성 (generate_tts.py로 생성)
public/videos/   강의 영상 mp4를 넣는 곳
generate_tts.py  스크립트로 TTS 음성을 만들고 시작 시각을 자동으로 맞춤
```
